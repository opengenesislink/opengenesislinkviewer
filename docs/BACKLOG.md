## First actions

1. Resolve [#1 — source import](https://github.com/opengenesislink/opengenesislinkviewer/issues/1)
   and [#2 — license audit](https://github.com/opengenesislink/opengenesislinkviewer/issues/2).
2. Establish reproducible OpenSim native builds [#3](https://github.com/opengenesislink/opengenesislinkviewer/issues/3)
   and [#4](https://github.com/opengenesislink/opengenesislinkviewer/issues/4).
3. Validate against [#5 — stock OpenSimulator](https://github.com/opengenesislink/opengenesislinkviewer/issues/5).
4. Only then begin custom viewer UI, economy and renderer changes.
